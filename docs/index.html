ゾートロープとは

ゾートロープの名は、ギリシア語の zoe（生命）と trope（回転）から。「生命の輪」「生きている輪」を意味します。

少しずつ違う絵を並べ、回すことで動いて見える仕組み。このスリップマットは、回転中にiPhoneで動画撮影（30fps）すると、キャラが踊って見えるように作れます。

回転プレビューと保存

撮影時の見え方をチェック。仕上がったらデータを保存。

プレビューをタップして回転を切り替え。ピンチ・マウスホイールで拡大、ドラッグで移動できます。

33⅓回転 タップで45回転

30fpsを模擬。実際の見え方は撮影条件で変わります。

PDFは304.8mm四方に3600×3600pxの画像を配置します。透過背景は白になります。
